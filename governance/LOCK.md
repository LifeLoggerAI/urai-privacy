# URAI-PRIVACY — LOCK

This repository contains URAI’s canonical privacy, trust, security,
and ethical commitments.

Once locked, changes to this repository require:
- Explicit version bumps
- Changelog entries
- Public disclosure where applicable

---

## Scope of This Lock

This lock applies to:
- Privacy Policy
- Terms of Service
- Trust Statement
- Ethics & AI Boundaries
- Data Control & Deletion
- Security & Law Enforcement Policy
- Children’s & International Disclosures

---

## Principles Frozen by This Lock

- No sale of raw personal data
- No training on user data by default
- No behavioral manipulation
- No dark patterns
- Explicit, revocable consent
- User-accessible deletion

Any change that weakens these principles
**must be treated as a breaking change**.

## Change Control

Changes require:
1. PR using the Trust Checklist
2. Legal & ethics review
3. Version bump
4. Changelog entry

Emergency changes must be documented post-hoc.

## Accountability

This lock exists to protect users first — not the company.

Responsibility for enforcement rests with the URAI founding team.
