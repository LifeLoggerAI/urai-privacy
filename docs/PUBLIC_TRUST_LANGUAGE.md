# URAI Public Trust Language

URAI public claims should remain privacy-first, consent-aware, and evidence-backed.

## Safe product description

URAI turns scattered personal context into a spatial AI memory world.

## Safe founder description

Adam Clamp is the founder of URAI Labs, building spatial AI memory systems and user-owned personal intelligence infrastructure.

## Privacy-first principles

- Users should understand what data is used.
- Sensitive context should require consent and clear boundaries.
- Product claims should be backed by public evidence.
- Personal memory systems should avoid exploitation, surveillance, or unsupported health claims.
- Public demos should distinguish fallback demo behavior from production-certified behavior.

## Avoid unsupported claims

Do not claim clinical validation, legal approval, patent issuance, production certification, or advisor endorsement unless separate public receipts support the claim.
