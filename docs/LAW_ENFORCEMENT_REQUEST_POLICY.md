# Law Enforcement and Government Request Policy

URAI should protect user privacy when responding to law enforcement, court, regulatory, or government requests.

## Core Principles

- Verify every request before action.
- Require valid legal process where applicable.
- Minimize disclosure to the narrowest lawful scope.
- Notify users unless legally prohibited or there is a credible safety reason not to.
- Preserve an auditable record of every request and response.
- Do not provide informal or curiosity access.

## Request Intake

Every request must record:

- request ID
- requesting agency or authority
- request date
- legal process type
- jurisdiction
- affected user or account identifiers
- data requested
- deadline
- reviewing owner
- response decision
- disclosure scope
- user notification status

## Review Requirements

Before disclosure, URAI should confirm:

1. The requester is legitimate.
2. The request is legally valid.
3. The requested scope is specific and proportionate.
4. The data exists and is covered by the request.
5. The disclosure does not exceed what is required.
6. User notice is sent unless prohibited.

## Emergency Requests

Emergency requests require documented good-faith belief of imminent risk of death or serious physical harm. Emergency disclosure must be narrowly scoped, reviewed after the fact, and logged.

## Transparency Reporting

URAI should publish periodic transparency summaries when feasible, including counts of requests received, complied with, rejected, and user notices sent.
