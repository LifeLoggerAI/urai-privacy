Privacy request

Start a privacy rights request.

Use this page to request data export, deletion, consent revocation, biometric deletion, explanation of sensitive insights, correction, opt-out, or privacy support. The production request workflow must create a request ID, verify identity where needed, route the request to the right team, and audit every step.

Current production status

This page is the public intake placeholder and operating specification for launch. A polished production launch requires authenticated request submission, request IDs, status tracking, internal queue routing, and audit logging before this is considered complete.

Request types

Supported privacy actions.

Export my data

Request a portable copy of account-linked data and user-visible records.

Delete my data

Request deletion across production systems, derived stores, and eligible backups.

Revoke consent

Withdraw permission for a specific purpose, data class, or feature scope.

Delete biometric data

Request deletion of biometric or identity-linked signals where applicable.

Explain an insight

Request an explanation for sensitive inference, personalization, or AI-derived outputs.

Correct data

Request correction of inaccurate account, profile, or user-facing data.

Opt out

Opt out of data-sharing, monetization, or other optional processing where applicable.

Report a concern

Report suspected privacy, security, breach, or data misuse concerns.

What a complete request flow must do

  • Create a request ID and confirmation receipt.
  • Authenticate the user or complete secure identity verification.
  • Route the request to privacy, security, legal, support, or engineering.
  • Track status from received to completed, rejected, or escalated.
  • Audit request creation, verification, action, completion, and admin access.
  • Notify the user when the request is completed or needs more information.
