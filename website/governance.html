Governance

The repo is built to be enforceable, not decorative.

URAI Privacy combines policy docs, machine-readable registries, JSON Schemas, cross-repo CI tooling, lifecycle architecture, SOPs, and release gates.

Release gate

A URAI feature is not release-ready unless data classes, consent tiers, retention/deletion behavior, export/explainability behavior, audit logging, and privacy review are complete.
