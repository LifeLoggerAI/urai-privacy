URAI Privacy

Privacy rules the whole URAI ecosystem must obey.

URAI Privacy is the public governance layer for consent, data classification, retention, deletion, export, anonymization, audit logging, incident response, and data-sharing enforcement across URAI.

View governance repo How governance works User rights

Consent first

Granular, revocable consent tiers for sensitive inference, biometrics, personalization, location, and anonymized data-sharing.

User rights

Export, deletion, revocation, explanation, and privacy-history controls are treated as product requirements.

Enforceable policy

Machine-readable registries, JSON Schemas, and CI checks define data classes, consent tiers, retention classes, audit events, and blocked uses.

No silent escalation

URAI features must not expand collection, inference, sharing, monetization, or retention without renewed review and consent.

What this repo contains

A public operating layer for privacy.

Policy registries

Canonical data classes, consent tiers, retention classes, audit events, and blocked data uses.

Implementation contracts

Firestore schema, API contract, adoption JSON Schemas, examples, and reusable validation scripts.

Operating playbooks

Lifecycle diagrams and SOPs for consent, deletion, export, incident response, admin access, and audits.

Public notices

Legal notice templates for privacy policy, biometrics, AI inference, data-sharing, minors, cookies, and user rights.

Operational draft status

URAI Privacy is built as a governance and enforcement package. Public legal templates and regulatory mappings still require qualified legal review before production launch.
