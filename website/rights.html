User rights

Users should be able to understand, control, export, and delete their data.

URAI Privacy treats user rights as product requirements, not afterthoughts. Sensitive insights should be explainable, consent should be revocable, and data should be portable and deletable where applicable.

Consent control

Users should be able to grant, deny, revoke, and review non-essential consent tiers.

Consent Revocation

Withdrawing consent must stop future processing for that purpose, record a dated revocation event, preserve only legally required evidence, and expose any deletion or export actions still available to the user.

Data export

Users should be able to request structured exports of account data, consent history, memories, insights, and privacy events.

Deletion

URAI should support record, category, date-range, biometric-only, and account deletion where applicable.

Insight explanation

Sensitive AI insights should explain source categories, data classes, consent tier, and available controls.

Data-sharing opt-out

Users must be able to opt out of future anonymized data-sharing participation.

Human review

Users should be able to request review of privacy-sensitive issues, failed requests, or concerning insights.
