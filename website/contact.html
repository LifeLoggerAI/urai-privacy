Privacy rights

privacy@urailabs.com

Security

security@urailabs.com
For vulnerabilities, suspected breaches, exposed credentials, admin misuse, or sensitive data exposure.

Account support

support@urailabs.com
For access, account, and product-support issues that are not security reports.

General governance

Open a GitHub issue only for non-sensitive documentation, governance, adoption, or broken-link questions.

Do not post sensitive data publicly

Do not open public GitHub issues containing user data, credentials, biometric data, suspected breaches, law enforcement requests, or specific privacy-rights requests. Send only the minimum sensitive detail needed in the initial private report.

What verification means

Mailbox routing has been verified. This does not by itself certify legal sufficiency, incident-response SLAs, or independent privacy acceptance; those remain separate launch gates.
