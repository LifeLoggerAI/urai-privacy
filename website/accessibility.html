Accessibility

Privacy controls should stay understandable and operable across different access needs.

The URAI Privacy public website is designed for keyboard navigation, visible focus, browser text scaling, responsive reflow, reduced-motion preferences, and semantic page structure. This is an implementation commitment, not an external accessibility certification.

Report an accessibility barrierOther contact routes

Keyboard and focus

Public links and controls should remain usable without a pointer and expose a visible focus indicator.

Zoom and reflow

Browser text scaling and narrow-screen reflow should preserve required information without forcing horizontal navigation.

Motion and cognition

The shared public shell honors reduced-motion preferences and uses direct language so privacy status and consequences do not depend on animation.

Report safely

Include the affected public page and the task you were trying to complete. Do not send credentials, user data, health information, or other sensitive records.

Authority boundary

This page does not represent external WCAG certification, legal sufficiency, protected production deployment, or independent acceptance unless those are separately verified.
