# Changelog

All meaningful changes to URAI Privacy & Data Governance are recorded here.

## 0.1.0-draft - Governance package initialization

### Added

- Operational privacy governance index
- Data classification and collection boundaries
- Consent tier model
- Retention and deletion standard
- Data export standard
- Anonymization and aggregation standard
- Regulatory alignment map
- Incident response playbook
- Audit logging standard
- Privacy review checklist
- Legal notice templates
- Firestore privacy schema contracts
- Privacy API contract
- CI validation script and GitHub Actions workflow

### Status

This version is intended to make `urai-privacy` enforceable across the URAI ecosystem. It is not a substitute for jurisdiction-specific legal review before production launch.
