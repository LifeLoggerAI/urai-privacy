# URAI Privacy Policy Template

> This template is operational product copy and must be reviewed by qualified counsel before public launch.

## What URAI Is

URAI is a passive personal intelligence system that helps users understand memories, habits, mood patterns, relationships, device context, and life rhythms. URAI is designed around privacy-by-architecture, user sovereignty, and minimal data exposure.

## Data We Collect

Depending on the features you enable, URAI may collect or infer:

- account information
- user-approved memories and transcripts
- device and app interaction metadata
- location context
- mood, mental load, relationship, and other sensitive insights
- optional voice, face, or other biometric-derived signals
- consent, export, deletion, and privacy request history

## Why We Use Data

URAI uses data to:

- provide the app experience
- generate user-facing insights
- support export, deletion, and consent controls
- improve reliability and safety
- personalize the companion experience when enabled
- create anonymized, cohort-level data products only when the user opts in

## User Controls

Users can:

- grant or revoke consent tiers
- export data
- delete records, categories, time ranges, biometric data, or accounts
- opt out of anonymized data-sharing participation
- view consent and privacy history
- request review of sensitive privacy issues

## Sensitive Inferences

URAI treats emotional, mental health, crisis, relationship, trauma, deception, and biometric-derived insights as sensitive. These require explicit consent and should include understandable explanations.

## Data Sharing

URAI does not sell raw identity-bearing personal records. Any anonymized data-sharing or licensing requires separate user opt-in, cohort-level protections, and audit logging.

## Retention

URAI retains data according to its retention class. Raw sensitive processing data should be short-lived by default. User memories remain until the user deletes them or closes the account unless another retention rule applies.

## Security and Incidents

URAI uses access controls, audit logs, deletion workflows, and incident response procedures to protect user data. Users should be notified when an incident materially affects their privacy.
