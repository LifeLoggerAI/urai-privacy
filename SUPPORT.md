# Support and Contact

This repo governs privacy, consent, data rights, retention, deletion, export, anonymization, audit logging, incident response, and cross-repo privacy enforcement for URAI.

## Public Website

- https://uraiprivacy.com

## Primary Contacts

- Privacy: privacy@urai.app
- Security: security@urai.app
- General URAI: hello@urai.app

## What to Open as a GitHub Issue

Open a GitHub issue for:

- missing governance docs
- policy clarification requests
- adoption questions
- product-repo rollout blockers
- non-sensitive template improvements
- non-sensitive validation errors
- broken links or documentation problems

## What Not to Open Publicly

Do not open public GitHub issues for:

- security vulnerabilities
- exposed credentials
- private user data
- suspected breaches
- biometric exposure
- law enforcement requests
- specific user-rights requests
- sensitive operational incidents

Use the private contact routes above instead.
